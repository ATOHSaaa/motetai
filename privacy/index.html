プライバシーポリシー

  • サイト名: motetai
  • URL: https://motetai.jp
  • 運営者: motetai編集部

2. 取得する情報

当サイトでは、以下の情報を取得する場合があります。

  • Cookie および類似技術により取得される情報（閲覧ページ、参照元、端末・ブラウザ情報など）
  • アクセス解析ツールにより取得される匿名化された利用状況データ

当サイトは、氏名・住所・電話番号など個人を特定できる情報を、ユーザーの同意なく意図的に収集することはありません。

3. 利用目的

取得した情報は、以下の目的で利用します。

  • 当サイトの品質向上・コンテンツ改善
  • アクセス状況の分析および利用傾向の把握
  • 広告・アフィリエイトの効果測定
  • 不正利用の防止およびセキュリティの確保

4. アクセス解析ツール

当サイトでは、以下のアクセス解析ツールを利用しています。

Google Analytics（GA4）

Google LLC が提供するアクセス解析サービスです。Cookie を使用して利用状況を収集し、当サイトは統計情報として閲覧数や行動傾向を分析します。収集されたデータは Google のプライバシーポリシーに基づいて管理されます。

  • Google ポリシー: https://policies.google.com/privacy
  • オプトアウト: Google Analytics オプトアウト アドオン

Microsoft Clarity

Microsoft Corporation が提供する行動分析ツールです。ページの閲覧状況や操作の傾向を把握するために Cookie 等を使用します。個人を特定する目的では利用しません。

  • Microsoft プライバシー: https://privacy.microsoft.com/ja-jp/privacystatement

Google Search Console

当サイトの検索パフォーマンスを把握するため、Google Search Console を利用しています。Search Console 自体はサイト訪問者の行動を個別に追跡するものではありませんが、サイト所有権の確認のため HTML タグを設置しています。

当サイトは、サイト運営のため以下を利用しています。記事内のリンクをクリックして商品・サービスが購入・契約された場合、当サイトに紹介料等が支払われることがあります。

広告・アフィリエイトリンクには Cookie 等が使用される場合があります。第三者配信事業者は、ユーザーの興味に応じた広告を表示するために Cookie を使用することがあります。記事によっては「PR」表記を行い、広告・プロモーションを含む場合があります。

記事の内容は編集部の独自の見解に基づいて作成していますが、収益化のため特定の商品・サービスを紹介する場合があります。掲載内容は記事公開時点の情報であり、最新性・正確性を保証するものではありません。

当サイトは、法令に基づく場合を除き、取得した情報を本人の同意なく第三者に提供しません。ただし、上記のアクセス解析・広告・アフィリエイトサービス提供者に、各サービスの利用規約に基づきデータが送信される場合があります。

7. Cookie の管理

ブラウザの設定により Cookie の受け入れを拒否・削除できます。ただし、Cookie を無効にした場合、当サイトの一部機能が正しく動作しない可能性があります。

8. 保有期間

取得した情報は、利用目的の達成に必要な期間保有し、不要となった場合は適切な方法で削除または匿名化します。各外部サービスのデータ保有期間については、各提供者のポリシーをご確認ください。
