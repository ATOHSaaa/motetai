よくある質問（FAQ）

ランニングデートは初デート向きですか？

競合の結論は「向いている人もいるが、全員向きではない」です。プロフィールや会話で運動習慣が分かり、3km程度の合意がある場合に限り可とします。迷ったら食事デートを先にしてください。

自分はフルマラソン経験者ですが相手は初心者。どうしますか？

距離を半分・タイム計測オフ・指導ゼロを約束します。大会話や自己ベストは2回目以降でも踏み込まないでください。

皇居ランは付き合う前でもOKですか？

経験がある・混雑とトイレを把握している場合は2回目以降で可です。初めての相手には公園一周の方が心理的ハードルが低いことが多いです。

走ったあとすぐ2回目を誘ってもいい？

お礼と感想のあと、別の屋内デートを1週間以内に送る流れが自然です。2回目の誘いを参照してください。

プロフィールで走り好きと書いている相手への誘い方は？

距離・ペース・ラン後カフェをセットで書くと、ランニングプロフィールの宣言と矛盾しません。初回から10kmは避けてください。

まとめ｜短距離・会話ペース・ラン後まで設計する

ランニングデートは、男性が距離・ペース・汗・休憩・カフェを先に潰すほど成功率が上がります。今日からの4ステップです。

  1. 2回目を主戦場に、3〜5km・会話ペース・タイム計測オフを約束する
  2. 服装と汗・メイクをLINEで共有し、指導と速度自慢をしない
  3. 60分前後で切り、ラン後カフェで会話を深める
  4. 終了後24時間以内にお礼と次の日時を送る

走るデートは、記録ではなく相手のペースが設計の中心です。相手が話しやすい速度を守って、試してみてください。
