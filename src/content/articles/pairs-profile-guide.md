Pairsで結果が出ない男性の90%以上は、**プロフィールの問題**です。アプリの使い方以前に、まずプロフィールを見直すことが最もROI（費用対効果）の高い改善です。

## 女性がスワイプする判断基準

Pairsのユーザー調査や口コミを分析すると、女性のスワイプ判断は以下の順番で行われています。

1. **メイン写真**（第一印象で8割決まる）
2. **年齢・身長・年収**
3. **自己紹介文の冒頭2行**
4. **サブ写真のバリエーション**
5. **趣味・価値観の一致感**

つまり、**写真が最重要**です。自己紹介文は写真で興味を持たれた後に読まれます。

## メイン写真の鉄則5つ

### 1. 顔がはっきり見える

- サングラス、マスク、遠景はNG
- 顔が画面の40%以上を占める構図が理想

### 2. 自然な笑顔

- 歯を見せた笑顔が最も好印象
- 緊張した硬い笑顔より、自然な微笑み

### 3. 清潔感のある服装

- 白やベージュのトップスが好印象
- シワのある服、汚れた靴は避ける

### 4. 背景はシンプル

- カフェ、公園、オフィスビル前など
- 自宅の散らかった部屋はNG

### 5. プロに頼むか、友人に撮ってもらう

- 自撮りは避ける（可能な限り）
- スマホで十分。一眼レフは不要

## サブ写真の構成テンプレート

| 枚数 | 内容 | 目的 |
|------|------|------|
| 1枚目 | 笑顔のバストアップ | 第一印象 |
| 2枚目 | 全身（清潔感のある服装） | 体型・スタイルの確認 |
| 3枚目 | 趣味（料理、スポーツ等） | 会話のきっかけ |
| 4枚目 | 旅行や外食 | ライフスタイルの共有 |
| 5枚目 | 友人との写真（1枚まで） | 社交性のアピール |

## 自己紹介文の書き方テンプレート

```
【基本情報】
30代 / 会社員 / 都内在住

【仕事】
IT系の会社で働いています。平日は忙しいですが、
休日はしっかりリフレッシュするタイプです。

【趣味】
・カフェ巡り（最近は下町の喫茶店にはまってます）
・料理（週末は自分で作ることが多いです）
・散歩（近所の公園を歩くのが日課です）

【求めている関係】
まずは気軽にお話しできて、自然体でいられる関係が理想です。
結婚を視野に入れた出会いを希望しています。

【お相手に求めること】
一緒にいて楽しい時間を過ごせる方と出会いたいです。
```

### 自己紹介で避けるべき表現

- 「普通の男性です」→ 具体性がない
- 「優しいです」→ 誰でも言える
- 「年収○○万」だけのアピール → 金銭感が強い
- ネガティブな過去の恋愛話

## プロフィール改善のチェックリスト

- [ ] メイン写真は笑顔で顔がはっきり見える
- [ ] サブ写真が3枚以上ある
- [ ] 自己紹介文に具体性がある（趣味、価値観）
- [ ] 結婚観・出会いの目的が明記されている
- [ ] 誤字脱字がない

> プロフィール改善は一度やれば長期間効果が続きます。週末の1〜2時間を投資するだけで、出会いの質が変わります。
