# Google コンテンツ品質ガイドライン

> AI で記事を生成する際の品質基準。Google 公式ドキュメント（2025年9月版 Search Quality Rater Guidelines、Search Central ドキュメント等）をもとに作成。

**参照元（公式）**

- [Creating helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)
- [Spam policies for Google web search](https://developers.google.com/search/docs/essentials/spam-policies)
- [Google Search's guidance about AI-generated content](https://developers.google.com/search/blog/2023/02/google-search-and-ai-content)
- [Search Quality Rater Guidelines（2025年9月11日版）](https://services.google.com/fh/files/misc/searchqualityevaluatorguidelines.pdf)

## 1. Google が明示的にペナルティを与えるもの

Google は「ランキング要因」として E-E-A-T を直接使うわけではないが、**スパムポリシー違反**や**品質基準を満たさないコンテンツ**に対して、検索結果での表示低下・除外・手動対応を行う。以下は公式に「違反」「Lowest 評価」「ランキング低下」の対象とされる行為・コンテンツ。

### 1-1. スパムポリシー違反（Search Essentials / Spam Policies）

| 種類 | 内容 |
|------|------|
| **クローキング** | ユーザーと検索エンジンに異なるコンテンツを見せる |
| **ドアウェイページ** | 似たクエリ向けに中間ページを大量生成し、最終目的地より有用性が低い |
| **期限切れドメイン悪用** | 信頼されていたドメインを買い、ユーザーに価値のないコンテンツを載せる |
| **ハッキングコンテンツ** | 権限なく挿入されたスパム・悪意あるコード |
| **隠しテキスト・隠しリンク** | 人間には見えない形でキーワードやリンクを埋め込む |
| **キーワード詰め込み** | 不自然なほどキーワードを繰り返す |
| **リンクスパム** | ランキング操作目的のリンク購入・交換・大量自動生成 |
| **スケールドコンテンツ悪用** | 大量の低品質・非オリジナルページをランキング目的で生成 |
| **スクレイピング** | 他サイトのコンテンツを改変せず（または微修正のみで）転載 |
| **サイト評判悪用** | 第三者コンテンツを、ホストサイトの評判だけで上位表示させる |
| **スニーキーリダイレクト** | ユーザーを意図しないページへ誤導するリダイレクト |
| **薄いアフィリエイト** | 商品説明をそのままコピーし、付加価値のないアフィリエイトページ |
| **ユーザー生成スパム** | コメント・フォーラム等への無関係な宣伝投稿 |
| **AI によるランキング操作** | AI でコンテンツを生成し、**主目的が検索順位の操作**である場合（スパムポリシー違反） |

**ペナルティの形態**

- 検索結果での**順位低下**
- 検索結果からの**除外**（インデックスされない・表示されない）
- **手動対応**（Search Console の Manual actions）
- ポリシー回避の継続行為には、サイト全体への広範な措置

### 1-2. 最低品質（Lowest）とみなされるコンテンツ

Search Quality Rater Guidelines（2025年9月版）で Lowest とされるものは、実質的に Google が「検索に載せるべきでない」水準。

**3つの大カテゴリ**

1. **有害（Harmful）** — 自己・他者・特定グループへの危害、誤情報による危害
2. **信頼できない（Untrustworthy）** — 欺瞞、虚偽、詐欺、E-E-A-T の著しい欠如
3. **スパム的（Spammy）** — 努力・独自性・付加価値がほぼない大量生成コンテンツ

**具体的な Lowest 条件（いずれか該当で Lowest）**

- ページの目的が有害、または真の目的・責任者を欺く
- ハッキング・改ざん・スパム投稿されたページ
- MC（メインコンテンツ）が意味不明・存在しない・極めて薄い
- **努力・独自性・付加価値がほぼゼロ**のコピー・言い換え・AI 生成コンテンツ
- スケールドコンテンツ悪用（大量のテンプレート記事、PAA 質問への薄い回答など）
- 著しく誤解を招くタイトル
- 広告で MC を故意に隠す・妨害する
- YMYL ページで責任者・著者情報が皆無
- 極めて悪い評判（詐欺、犯罪行為の報道など）
- 事実と異なる情報、根拠のない陰謀論、専門家のコンセンサスと矛盾する YMYL 情報

### 1-3. 検索エンジン優先（search engine-first）コンテンツ

Helpful Content System の対象。以下に「はい」と答えられるなら、ペナルティ・評価低下のリスクが高い。

- 主目的が検索エンジンからの訪問獲得である
- 多くのトピックに薄い記事を大量投入している
- 広範な自動化で多トピックのコンテンツを生成している
- 他者の要約だけで独自の価値をほとんど加えていない
- トレンドだから書いている（既存読者には不要なトピック）
- 読者が「また検索しないと」と感じる内容
- 文字数や更新日の操作で freshness を偽る
- 実 expertise がないニッチに、検索流入目的だけで参入している

## 2. 「人間が読むための、人間にとって有益な記事」とは何か

Google の公式表現は **people-first content（人間優先コンテンツ）**。検索順位のために作るのではなく、**人のために作り、人が役立つ**コンテンツ。

### 2-1. 人間優先コンテンツの定義

> 主に**人のために**作られ、検索エンジンのランキング操作のために作られていないコンテンツ。

**「はい」なら人間優先の可能性が高い**

| 質問 | 意味 |
|------|------|
| 既存・想定読者が、直接サイトに来ても有用と感じるか？ | 実在するニーズへの応答 |
| 一次体験や深い知識が明確に示されているか？ | 実際に使った・行った・経験した根拠 |
| サイトに明確な主目的・フォーカスがあるか？ | 何でも屋ではない専門性 |
| 読後、目標達成に十分な情報を得たと感じるか？ | 完結性・実用性 |
| 満足感のある読後体験を提供するか？ | UX・読みやすさ・信頼感 |

### 2-2. 高品質 MC（メインコンテンツ）の基準

Rater Guidelines では、高品質 MC は次の特徴を持つ。

- **相当な努力（Effort）** がかけられている
- **独自性（Originality）** がある
- **才能・技能（Talent/Skill）** が求められる分野ではそれが示されている
- ページの目的を**十分に達成**している

逆に、類似ページと比べて**努力・独自性・付加価値がほぼない**コンテンツは Lowest。

### 2-3. Google が「有益（helpful）」とみなすコンテンツの特徴

公式の自己評価質問から抽出した要点。

**コンテンツと品質**

- オリジナルの情報・調査・分析を提供している
- トピックを十分・包括的に説明している
- 自明でない洞察や興味深い情報がある
- 他ソースを参考にしても、丸コピーではなく独自の付加価値がある
- タイトルは内容を正確に要約し、誇張・煽りではない
- ブックマーク・共有・推薦したくなる内容か
- 雑誌・百科事典・書籍に載る水準か
- 検索結果の他ページと比べて実質的な価値がある
- 誤字・体裁の乱れがなく、丁寧に作られている

**専門性**

- 信頼できる形で情報が提示されている（出典、著者、About ページ）
- サイト・著者がそのトピックの権威として認知されている
- 専門家・熱心な実践者が書いている／レビューしている
- 事実誤認が容易に検証できる形でない

### 2-4. Who / How / Why フレームワーク

Google が推奨するコンテンツ評価の軸。

| 軸 | 問い | 人間優先の実装 |
|----|------|----------------|
| **Who** | 誰が作ったか明確か？ | 著者名・プロフィール・経歴・専門分野を明示 |
| **How** | どう作ったか分かるか？ | 調査方法・体験の根拠・AI 利用の開示（必要な場合） |
| **Why** | なぜ作ったか？ | 読者の問題解決が主目的。SEO が主目的なら NG |

### 2-5. YMYL（Your Money or Your Life）への注意

健康・財務・安全・社会福祉に影響するトピックは、より高い信頼性が要求される。

- 体験談の共有は価値があるが、**医療・投資・法律の具体的アドバイスは専門家の領域**
- 事実の正確性・出典・著者の専門性がより厳しく問われる

## 3. E-E-A-T の4要素とページでの体現方法

E-E-A-T は Experience（経験）・Expertise（専門性）・Authoritativeness（権威性）・Trustworthiness（信頼性）の頭文字。**Trust（信頼性）が最も重要**で、他の3つは信頼を支える要素。

> E-E-A-T 自体は単一のランキング要因ではないが、良い E-E-A-T を持つコンテンツを見つけるための複数のシグナルの組み合わせとして使われる。

### 3-1. Experience（経験）

**意味:** コンテンツ作成者が、そのトピックについて必要な**一次体験・生活経験**を持っているか。

**ページでの体現**

- 「実際に使った」「実際に行った」「自分が試した」という具体エピソード
- 商品レビューでの使用感・写真・使用期間の記述
- 婚活・マッチングアプリ記事での実体験に基づく失敗談・成功談
- 手順記事での実際の作業写真・スクリーンショット
- 「私の場合は〜だった」という個人の文脈（ただし YMYL では体験と専門的助言を区別）

**NG 例:** 使ったことのない商品のレビュー、行ったことのない場所の詳細ガイド

### 3-2. Expertise（専門性）

**意味:** コンテンツ作成者が、そのトピックに必要な**知識・技能**を持っているか。トピックごとに求められる専門性のレベルは異なる。

**ページでの体現**

- 著者の資格・職歴・実績の明示（プロフィールページへのリンク）
- 専門用語を正しく使い、初心者にも分かる説明を添える
- 根拠・データ・出典の提示
- レビュー・監修者の記載（YMYL では特に重要）
- 内容の正確性（事実誤認がない）

**NG 例:** 医療・法律・投資の具体的助言を、専門知識のない著者が断定する

### 3-3. Authoritativeness（権威性）

**意味:** そのコンテンツ作成者またはサイトが、トピックについて**頼りになる情報源（go-to source）**として知られているか。

**ページでの体現**

- サイト全体のテーマとの一貫性（何でも屋サイトは権威性が分散）
- 外部からの引用・メディア掲載・受賞歴
- その分野で継続的に質の高いコンテンツを発信している実績
- 公式情報源への適切な参照（政府・学術・業界団体など）
- 著者がその分野で認知されている（SNS・出版物・講演等）

**NG 例:** 料理ブログで税務フォームを提供、全く関係のないトピックの乱立

### 3-4. Trustworthiness（信頼性）★最重要

**意味:** ページが**正確・誠実・安全・信頼できる**か。ページの種類によって必要な信頼のレベルは異なる。

**ページでの体現**

| ページ種別 | 信頼性の体現 |
|-----------|-------------|
| EC・サービス | 安全な決済、返品・問い合わせ先、実在企業情報 |
| レビュー | 正直な評価、利益相反の開示（アフィリエイト・提供品の明示） |
| YMYL 情報 | 事実の正確性、専門家の監修、更新日、出典 |
| 一般記事 | 誇大広告でない、タイトルと内容の一致、著者の明示 |

**信頼を損なう要素**

- 著者・運営者情報の皆無（YMYL では致命的）
- 利益相反の隠蔽（メーカー「レビュー」、ステマ）
- 事実誤認・誇大なタイトル
- 広告が MC を隠す欺瞞的デザイン
- 極めて悪い評判（詐欺・訴訟・報道）

### 3-5. E-E-A-T の評価に使う3つの情報源

Rater Guidelines が示す評価の観点（記事作成時にも使える）。

1. **サイト・著者が自分について言っていること** — About ページ、プロフィール
2. **他者がサイト・著者について言っていること** — 独立したレビュー、報道、引用
3. **ページ上に見えること** — MC の質、コメント、実際の内容から分かる専門性

## 4. 記事公開前チェックリスト

公開前に以下をすべて確認する。1つでも重大な NG があれば公開を見送り、修正する。

### A. 目的と姿勢（Why）

- [ ] この記事は**読者の問題解決**が主目的である（SEO が主目的ではない）
- [ ] 想定読者が誰か明確で、その人にとって有用な内容である
- [ ] 検索キーワードに合わせて無理に書いていない（ニッチ参入の合理性がある）

### B. 独自性と品質（What）

- [ ] 競合記事と比べて**独自の情報・体験・分析**がある（丸コピー・言い換えのみではない）
- [ ] トピックを**十分・包括的**にカバーしている
- [ ] 事実誤認がない（特に YMYL トピックは出典を確認）
- [ ] 誇大・煽りのないタイトルと見出し
- [ ] 誤字・体裁の乱れがない
- [ ] AI 生成部分に人間による**編集・検証**が入っている

### C. E-E-A-T

- [ ] **Who:** 著者名・プロフィールが明示されている（読者が期待する場合）
- [ ] **How:** 体験・調査・データの根拠が書かれている
- [ ] **Experience:** 一次体験に基づく記述がある（該当トピックの場合）
- [ ] **Expertise:** トピックに見合った知識レベルである
- [ ] **Trust:** 出典・利益相反（アフィリエイト等）の開示がある
- [ ] YMYL トピックの場合、専門家の監修または公式情報源への参照がある

### D. スパム・ペナルティ回避

- [ ] キーワード詰め込み・不自然な繰り返しがない
- [ ] 他サイトのコンテンツのコピー・軽微な言い換えではない
- [ ] テンプレートの使い回し感がない（スケールドコンテンツ悪用に該当しない）
- [ ] 更新日や文字数の操作をしていない
- [ ] アフィリエイト記事に**独自のレビュー・比較・体験**がある
- [ ] AI をランキング操作目的で使っていない

### E. ユーザー体験

- [ ] 読後に「また検索しないと」と感じさせない完結性がある
- [ ] 見出し構造が論理的で読みやすい
- [ ] 具体例・表・チェックリスト等で実用性がある
- [ ] 内部リンクが適切（関連記事への導線）
- [ ] モバイルでも読みやすい

### F. 技術・メタ情報

- [ ] タイトル・description にメイン KW を自然に含む
- [ ] `targetKeyword` 等の frontmatter が正しい
- [ ] `npm run build` が通る
- [ ] 太字・テンプレートブロックのパースエラーがない

### G. 最終確認（他人の目）

- [ ] サイトに関係のない人に読ませ、理解度・信頼感・有用性を確認した
- [ ] 「この記事をブックマーク／友人に送るか？」に自信を持てる

## 付録: AI 生成コンテンツに関する Google の公式スタンス

- AI 利用自体は**ポリシー違反ではない**
- **主目的が検索順位の操作**ならスパムポリシー違反
- AI は特別扱いされない。「ただのコンテンツ」として品質で評価される
- 有用・オリジナル・人間優先・E-E-A-T を満たせば評価される可能性がある
- AI 著者名の掲載は推奨されない。代わりに**人間の編集者・監修者**を明示する
- AI 利用は「How was this created?」と思われる場合に開示を検討する
